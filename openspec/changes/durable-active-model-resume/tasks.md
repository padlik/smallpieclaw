## Verification ownership and evidence budget

The implementation specialist owns focused red/green evidence for tasks 1–4; one test-execution specialist owns the final static/full-suite commands after all writers are reconciled. The OpenSpec verifier owns spec-to-implementation traceability when the user requests verify. Avoid duplicate full-suite runs unless later edits invalidate evidence.

Preferred evidence is deterministic controller/ReactContext integration plus captured adapter transport payloads, checkpoint bytes and executor call counts. Pure mocked wait assertions alone cannot establish no blocking, actual-send retirement or cross-provider continuity. Live provider/Telegram manual smoke is supplementary, not required proof and not a reason to add dependencies; deterministic tests do not promise universal model compatibility. Existing tool-confirmation and headless-run regressions provide the unchanged-boundary evidence.
