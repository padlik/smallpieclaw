## 1. Storage layer (`FileTokenStorage`)

- [ ] 1.1 Add `read_issued_at() -> float | None` — synchronous read returning `token.issued_at`; returns `None` when the file, the `token` block, or the `issued_at` key is absent or the value is not a real number. No event loop required (mirrors `read_status`).
- [ ] 1.2 Add `async get_oauth_metadata() -> OAuthMetadata | None` and `async set_oauth_metadata(metadata: OAuthMetadata) -> None`: `set` merges the block (`model_dump(mode="json", exclude_none=True)`) into the existing file via the existing `_atomic_write` (0600, tmp+rename); `get` logs a warning naming the server and returns `None` on a malformed block rather than raising (mirrors the `client_info` fallback, `mcp_oauth.py:216-242`).
- [ ] 1.3 Extend `set_tokens` payload assembly to carry the stored `oauth_metadata` block forward alongside `client_info`: a block present on disk before the write is preserved after it (ADR-0031; the ADR-0029 merge-preserve lesson generalized to the new key).

- [ ] 3.1 Drift guards (executable `inspect.getsource` assertions, b9b3a24 pattern): (a) SDK `OAuthClientProvider._initialize` contains no `token_expiry_time` write (upstream #1784 landing trips this → remove the 2.1 restore); (b) SDK `_refresh_token` still reads `oauth_metadata.token_endpoint` with the `urljoin(base_url, "/token")` fallback (#2492/#2875 landing trips this → re-verify the metadata restore); (c) the flow still calls `await self._handle_token_response(` (orphan-detection for 2.2, mirroring the existing `_handle_refresh_response` pin).
- [ ] 3.2 `read_issued_at` matrix: present → value; no file / no `token` block / no `issued_at` key / non-numeric value → `None`; synchronous (no event loop needed).
- [ ] 3.3 `get`/`set_oauth_metadata` round-trip; malformed block → warning naming the server + `None`, no exception.
- [ ] 3.4 Ordering tests: `set_oauth_metadata` is only reachable after `set_tokens` (a metadata-only file state is unreachable — pin it); `set_tokens` carries `oauth_metadata` and `client_info` forward across a silent refresh (the ADR-0029 RT-survival parallel).
- [ ] 3.5 `_initialize` restore matrix: `issued_at + expires_in` → expiry set from the file; `issued_at` missing → expiry stays `None`; `expires_in` missing → `None`; no token → no-op; metadata restored when present; malformed metadata → `context.oauth_metadata is None` (assert the value, not "unchanged").
- [ ] 3.6 Metadata-persist path (the `_handle_token_response` override): (a) drive a **successful** token exchange with `context.oauth_metadata` set → assert the `oauth_metadata` block is persisted to the token file (containing `token_endpoint`) and that `set_tokens` stamped `issued_at` first (persist strictly after the exchange); (b) drive a flow that **fails before the exchange completes** → assert **no** `oauth_metadata` block is written. Covers the frozen scenario "OAuth metadata persisted after a completed authorization" end-to-end — a persist bug here would ship the exact production defect this change fixes with the suite green.
